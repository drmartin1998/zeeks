# Implementation Plan: About Us Page

**Branch**: `026-about-us-page` | **Date**: 2026-08-04 | **Spec**: [spec.md](./spec.md)

## Summary

Create a static "About Us" page at `/about` that displays the store's founding story, product specialties, and physical address. Uses the existing design system — dark hero header (CategoryHero-style), narrative content sections, and a CTA to browse products. Also fixes the dead footer "About Us" link (`href="#"` → `href="/about"`).

## Technical Context

**Language/Version**: TypeScript 5, React 19, Next.js 16 (App Router)
**Primary Dependencies**: next/link, existing Footer component, existing Button component
**Assets**: None required (text-only content; no new images)
**Storage**: N/A
**Testing**: Vitest, Playwright (E2E)
**Target Platform**: Vercel (Node.js serverless)
**Project Type**: Next.js web application (App Router)
**Performance Goals**: Page renders in <500ms (static content, no data fetching)
**Constraints**: Server Component by default; no `"use client"` needed; page brings its own `<Footer />` (same pattern as home page)
**Scale/Scope**: 1 new route file (`app/about/page.tsx`), 1 footer fix (`components/footer.tsx`), no new API routes, no new components, no new dependencies

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| No separate AboutHero component | Page is simple enough to inline the hero section in `page.tsx`. No reusability needed. |
| No `"use client"` directive | No interactivity required — pure static content. |
| Footer fix is part of this feature | The footer is the only other place linking to `/about`; fixing the dead link is a natural part of delivering the feature (FR-002). |
| Address hardcoded as text | Source page doesn't include hours/phone; no Square Locations API needed for this feature. |
| No background image | Source content doesn't reference one; keeps implementation simple. |
