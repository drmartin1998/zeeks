# Quickstart: Navigation Location Bar

**Feature**: Navigation Location Bar
**Date**: 2026-08-03

## Overview

This guide covers validation scenarios to verify the Navigation Location Bar feature works end-to-end. It does not include implementation code — see `tasks.md` for implementation tasks.

## Prerequisites

- Square sandbox/production credentials in `.env.local` (`SQUARE_ACCESS_TOKEN`, `SQUARE_LOCATION_ID`)
- The Square location has `businessHours.periods[]` configured for at least one day
- Dev server running: `vercel dev` on port 3000
- TypeScript and lint passing: `tsc --noEmit && npm run lint`

## Validation Scenarios

### VS-01: Location and hours render on homepage

1. Start the dev server: `vercel dev`
2. Visit `http://localhost:3000`
3. **Expected**: The navigation bar shows the store's city (e.g., "Seattle, WA") and today's hours (e.g., "Open today: 9 AM – 9 PM") with a status indicator

### VS-02: Open/Closed status is correct for current time

1. Verify the Square location has business hours for today
2. Visit any page
3. **Given** current time is within operating hours → status shows "Open Now"
4. **Given** current time is within 30 minutes of closing → status shows "Closing Soon"
5. **Given** current time is outside operating hours → status shows "Closed Now"

### VS-03: Location bar visible on all pages

1. Navigate between: `/`, `/categories/miniatures`, `/shop`, `/about`, `/cart`
2. **Expected**: Location bar content (city + hours + status) is consistently visible on every page

### VS-04: Graceful degradation on API failure

1. Temporarily invalidate `SQUARE_ACCESS_TOKEN` in `.env.local`
2. Restart dev server
3. Visit any page
4. **Expected**: Navigation links, logo, search, cart, and auth buttons render normally. The location bar section is absent (hidden).
5. Restore correct token and restart

### VS-05: Screen reader accessibility

1. Open browser dev tools Accessibility panel or use a screen reader
2. Visit any page
3. **Expected**: The city, hours text, and status indicator are announced as readable text on page load

### VS-06: Midnight-spanning hours

1. Configure Square business hours with a period that spans midnight (e.g., 08:00 PM – 02:00 AM)
2. Visit the site at 11:00 PM (within hours) → **Expected**: "Open Now"
3. Visit at 01:00 AM (still within the span) → **Expected**: "Open Now"
4. Visit at 03:00 AM (outside) → **Expected**: "Closed Now"

### VS-07: No hours defined today

1. Remove today's hours period from the Square location (or visit on a day with no hours configured)
2. Visit any page
3. **Expected**: Status shows "Closed Today" or the hours portion is hidden
